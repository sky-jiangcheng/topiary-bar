已知限制

  • Status Bar（accessory）应用无法通过 NSRunningApplication.activate() 前置，需改用 openApplication 重新唤起；个别 accessory 应用（如 Macs Fan Control）系统层面不允许被其他应用唤起
  • 应用类型基于 activationPolicy 推断，无法读取状态栏图标的真实归属
  • 菜单栏图标初始位置由系统决定（首次落在最左侧、靠刘海）。⌘-拖动一次即可固定，位置跨启动保留
  • 不隐藏其他应用的真实菜单栏图标（AX 隐藏方案已于 v1.6.0 移除），需精简请搭配 Hidden Bar / Ice 等工具；这些工具运行时本应用不会误报刘海遮挡
  • Mac App Store 版受沙盒限制，NSRunningApplication.terminate() 被系统拦截，因此不含退出功能
  • 应用图标没有深色变体：macOS 26 起系统读取资产目录里的 Assets.car 并自己套形状，因此目录内必须是满幅方图；而 actool 不接受 mac 图标的深色外观声明（十槽与单尺寸两种写法都被判为未分配），真正的深色 app icon 需要 Icon Composer 的分层 .icon 格式。macOS 14/15 仍读 AppIcon.icns，那条路径不会套形状，所以 .icns 自带圆角
  • 弹窗与主窗口的搜索框各自独立、互不同步 — 这是刻意的设计决策：弹窗面向瞬时快速查看，主窗口面向常驻管理，搜索场景不同

Features

🔍 Auto detection

Classifies Status Bar vs. Dock apps using activationPolicy

⚡ One-click actions

Open, pin, or quit apps — quit escalates to a force kill if the app is still alive after 3 s

📌 Resident menu bar icons

Pin apps to live directly in the macOS menu bar — always visible, one click to activate

🔎 Search & filter

Filter by name or bundle identifier, narrowed by app type

📊 Memory insight

System memory card plus a per-app memory footprint, read locally and never uploaded

⌨️ Global hotkey

⌃⌥M summons the main window by default; rebind or disable it (Carbon registration, no Accessibility permission)

🚀 Launch at login

Optional start-at-login claims a stable spot near the right edge of the menu bar

🛟 Notch self-healing

Detects an icon swallowed by the notch and surfaces the manager window, so the background agent is never unreachable

🎨 Themes

System, light, and dark, applied instantly across the app

🌍 Languages

English, 简体中文, 日本語, Deutsch, Español

🎛️ Icon styles

Dots, grid, chevron, square, circle, or transparent

🔒 No permissions

Runs without requesting any system access; no data leaves the device

Known limitations

  • Status Bar (accessory) apps cannot be foregrounded with NSRunningApplication.activate() — Topiary re-launches them via openApplication; a few accessory apps (e.g. Macs Fan Control) can't be raised by other apps at all
  • App typing is based on activationPolicy, so the real owner of a menu bar icon cannot be read
  • The menu bar icon's initial position is system-controlled (fresh items land leftmost, next to the notch). ⌘-drag it once to where you want it; the position is remembered across launches
  • Topiary does not hide other apps' real menu bar icons (AX-based hiding was removed in v1.6.0). Pair it with Hidden Bar / Ice for that — occlusion warnings are suppressed automatically while one runs
  • The Mac App Store build is sandboxed and NSRunningApplication.terminate() is blocked, so Quit is compiled out of that channel
  • The app icon has no dark variant: on macOS 26+ the system reads Assets.car and applies the icon shape itself, so the catalog must hold full-bleed square artwork; actool refuses dark appearance declarations for mac app icons (both the ten-slot and single-size layouts come back as unassigned), and a real dark app icon needs Icon Composer's layered .icon format. macOS 14/15 still read AppIcon.icns, which is never masked by the system, so that copy carries its own rounded corners
  • The popover and the main window deliberately keep independent search fields — a design decision: the popover is a transient quick glance, the main window is the standing manager, and the two search contexts differ
