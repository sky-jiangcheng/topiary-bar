Topiary 隐私政策

最后更新：2026年9月27日

Topiary 不收集、存储、共享或出售任何个人数据。

数据收集

Topiary 不收集分析数据、跟踪数据、账户信息、联系信息、位置数据或标识符。

本地设备信息

Topiary 使用公共 macOS API（NSWorkspace.shared.runningApplications）列出本机正在运行的应用程序。这些信息只在设备上本地处理，不会传输到任何服务器。

权限

Topiary 不请求辅助功能（Accessibility）权限，也不请求屏幕录制、输入监控、文件访问、网络访问或自动化权限。所有信息在您的设备上本地处理。

数据共享

由于 Topiary 不收集个人数据，因此不与第三方共享个人数据。

Topiary Privacy Policy

Last updated: September 27, 2026

Topiary does not collect, store, share, or sell any personal data.

Data collection

Topiary collects no analytics, tracking data, account information, contact information, location data, or identifiers.

On-device information

Topiary uses public macOS APIs (NSWorkspace.shared.runningApplications) to list apps running on your Mac. This information is processed locally and is never transmitted to any server.

Permissions

Topiary does not request Accessibility permission, nor screen recording, input monitoring, file access, network access, or automation. All information is processed locally on your device.

Data sharing

Because Topiary collects no personal data, no personal data is shared with third parties.
